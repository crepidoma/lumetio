# テンプレートリファレンス

日報テキストや工数 CSV の形を、テンプレートで決める方法をまとめる。
決まりそのもの (ファイルの置き場所、値の意味など) は [設計書](design.md) の §6.1、§6.2、§7 が正。
この文書は書き方と例を扱う。

## 1. ファイルの置き場所と種類

データフォルダの `templates/` に、1 つの出力につき 1 ファイルを置く。

| ファイル名 | 種類 | 名前 |
| --- | --- | --- |
| `日報テキスト.tmpl` | テキストの出力 | 日報テキスト |
| `工数CSV.csv.yaml` | CSV の出力 | 工数CSV |
| `日報.set.yaml` | 出力セット (いくつかの出力をまとめて作る組み合わせ) | 日報 |

- 名前は、ファイル名から種類と拡張子を除いた部分。
- 名前は、種類を問わず `templates/` の中で重ならないようにする。
  重なると、その名前のファイルはどれも使えない。
- 書き方に誤りのあるファイルは使えず、理由が知らされる。
  ほかのファイルは使える。
- 名前の形 (`*.tmpl`、`*.csv.yaml`、`*.set.yaml`) に合わないファイルと、`templates/` の中のフォルダは読まない。

## 2. テキストの出力 (`*.tmpl`)

```
---
file: "'report_'yyyyMMdd"
extension: txt
---
{{date "yyyy/MM/dd(EEE)"}} の日報

■ やったこと
{{- range .projects}}
- {{.name}}{{if .counted}} ({{.time}}){{end}}
{{- range .tasks}}
  - {{.title}}{{if .counted}} ({{.time}}){{end}}
{{- end}}
{{- end}}
```

先頭の `---` で囲んだ部分に設定を書き、その後に本文を書く。

| 設定 | 中身 |
| --- | --- |
| `file` | ファイル名の書式 (§4 の `date` と同じ書式)。必須 |
| `extension` | 拡張子。`.` は付けない。必須 |
| `encoding` | `utf-8` (省略時) か `utf-8-bom` |
| `newline` | `lf` (省略時) か `crlf` |

- `file` と `extension` には、`/ \ : * ? " < > |` を使えない。
- 本文は Go の [`text/template`](https://pkg.go.dev/text/template) の書き方そのまま。

## 3. テンプレートに渡す値

以下の例は、次の日の記録から作ったもの。

```yaml
date: 2026-03-09
tasks:
  - title: 画面の実装
    project:
      code: DEV-001
      name: 新機能
    time: [90m]
  - title: 週次ふりかえり
    project:
      code: MTG-01
    tags: [ふりかえり]
    note: 見積りが甘かった
    time: [30m]
  - title: 調査
    project:
      code: DEV-001
      name: 新機能
    untimed: true
  - title: 雑談
    exclude: true
    time: [15m]
notes:
  在宅: true
```

メモ欄は「在宅」(真偽値) と「連絡」(テキスト) を定義している。この日は「連絡」を書いていない。

### 全体

| 値 | 中身 | 例 |
| --- | --- | --- |
| `.date` | 日付 | `2026-03-09` |
| `.tasks` | その日の記録の並び。予定 (まだ実施済にしていないもの) は入らない | |
| `.projects` | プロジェクトごとのまとまり。そのプロジェクトが最初に出てくる記録の順 | |
| `.total_minutes` | 計上する時間の合計 (分) | `120` |
| `.total_time` | 計上する時間の合計 (`H:mm`) | `2:00` |
| `.notes` | メモ欄。`.notes.連絡` のように欄の名前で参照する | |

### `.tasks` の各要素

| 値 | 中身 |
| --- | --- |
| `.title` | タスクの名前 |
| `.project.code`、`.project.name` | プロジェクト。名前がなければ `name` はコードと同じ。プロジェクトがなければどちらも空 |
| `.tags` | タグの並び |
| `.note` | タスクのメモ |
| `.exclude` | 計上しない |
| `.minutes`、`.time` | 時間 (分と `H:mm`)。時間がなければ (時間不定か時間未入力) `0` と `0:00` |
| `.untimed` | 時間不定 (`untimed: true` の記録)。時間未入力 (時間を入れ忘れた記録) は含まない |
| `.counted` | 計上して、時間もある |

### `.projects` の各要素

| 値 | 中身 |
| --- | --- |
| `.code`、`.name` | プロジェクト。`name` は最初の記録のもの。プロジェクトのない記録のまとまりは、どちらも空 |
| `.minutes`、`.time` | 計上する時間の合計 |
| `.counted` | 計上する時間がある |
| `.has_untimed` | 計上する記録に、時間不定のものがある |
| `.tasks` | そのプロジェクトの記録。要素は `.tasks` と同じ |

### `.notes`

- 設定にあるメモ欄は、その日に書いていなくても空の値で入る。
- 設定から消した欄でも、その日の日次ファイルに値があれば入る。
- テキストの欄は文字列、真偽値の欄は `true` か `false`。
- 名前に空白や記号があるとき、名前が数字で始まるときは、`{{index .notes "朝の 連絡"}}` のように書く。

### `range` と `with` の中の `.`

`{{range}}` と `{{with}}` の中では、`.` がその要素に変わる。
全体の値は `$` から参照する。

```
{{range .tasks}}{{$.date}} {{.title}}
{{end}}
```

```
2026-03-09 画面の実装
2026-03-09 週次ふりかえり
2026-03-09 調査
2026-03-09 雑談
```

## 4. 関数

Go の組み込みの関数 (`and`、`or`、`not`、`eq`、`ne`、`lt`、`le`、`gt`、`ge`、`len`、`index`、`print`、`printf` など) に加えて、次の関数を使える。

| 関数 | 中身 |
| --- | --- |
| `date 書式` | その日の日付を書式で出す |
| `duration 分 書式` | 分を長さの書式で出す |
| `where 一覧 "項目" 値` | 一覧から、項目が値に合う要素を残す |
| `has 一覧 値` | 文字列の一覧 (`tags`) が値を含むか |
| `join 一覧 区切り` | 文字列の一覧 (`tags`) を区切りでつなぐ |

`has` と `join` に `.tasks` などの文字列でない一覧を渡すと、エラーになる。

### `date`

| 記号 | 意味 | 2026 年 3 月 9 日 |
| --- | --- | --- |
| `yyyy`、`yy` | 年。`yy` は下 2 桁 | `2026`、`26` |
| `MM`、`M` | 月。`MM` は 2 桁にそろえる | `03`、`3` |
| `dd`、`d` | 日。`dd` は 2 桁にそろえる | `09`、`9` |
| `EEE`、`EEEE` | 曜日 | `月`、`月曜日` |
| `'…'` | 文字をそのまま出す。`''` で `'` を出す | |

- 英字以外 (`/`、`-`、日本語など) はそのまま出る。
- 表にない英字はエラーになる。
  英字を出したいときは `'…'` で囲む。
- 時刻 (`HH`、`mm` など) は使えない。

```
{{date "yyyy年M月d日 EEEE"}}
```

```
2026年3月9日 月曜日
```

出力の `file` も同じ書式で書く (`"'report_'yyyyMMdd"` は `report_20260309`)。

### `duration`

| 記号 | 意味 |
| --- | --- |
| `H`、`HH` | 時間。`HH` は 2 桁にそろえる |
| `m`、`mm` | 分。`mm` は 2 桁にそろえる |
| `'…'` | 文字をそのまま出す。`''` で `'` を出す |

- `H` がなければ、分に時間の分も入る (90 分を `m` で書くと `90`)。
- 書式の中でいちばん小さい単位は、余りを小数で出す (90 分を `H` で書くと `1.5`)。
  小数は最大 2 桁。

```
合計 {{.total_time}} ({{duration .total_minutes "H'h'"}})
```

```
合計 2:00 (2h)
```

### `where`

- 項目の値が一覧 (`tags`) なら、値を含む要素を残す。
- それ以外の項目は、値が等しい要素を残す。
- 項目は `project.code` のように `.` でたどれる。
- 一覧には `.tasks`、`.projects`、`where` の結果などを渡す。
- ない項目を書くとエラーになる。
  ただし、項目は要素ごとに確かめるので、一覧が空のときは、ない項目でもエラーにならず空の一覧になる。

```
{{range where .tasks "project.code" "DEV-001"}}{{.title}}
{{end}}
```

```
画面の実装
調査
```

件数は `len` で数える。

```
ふりかえり {{len (where .tasks "tags" "ふりかえり")}} 件
```

```
ふりかえり 1 件
```

### `has`

1 件ずつの条件分岐に使う。
`not` と組み合わせると、「含まないもの」を選べる。

```
{{range .tasks}}{{if not (has .tags "ふりかえり")}}{{.title}}
{{end}}{{end}}
```

### `join`

```
{{range .tasks}}{{.title}}{{with .tags}} [{{join . ", "}}]{{end}}
{{end}}
```

```
画面の実装
週次ふりかえり [ふりかえり]
調査
雑談
```

## 5. 空白と改行

`{{` と `}}` の外の文字は、改行も含めてそのまま出る。
`{{range}}` などを別の行に書くと、その行の改行も出てしまう。
Go の書き方どおり、`{{-` で前の空白と改行を、`-}}` で後ろの空白と改行を詰める。

日報の見出しと箇条書きは、**各要素が自分の改行で始まり、`{{-` で前の改行を詰める** 形にすると、空行が混ざりにくい。

```
■ やったこと
{{- range .projects}}
- {{.name}}
{{- end}}

■ 連絡
```

```
■ やったこと
- 新機能
- MTG-01
- 

■ 連絡
```

## 6. よくある書き方

### あるときだけ見出しを出す

`with` は、値が空 (空の一覧、空の文字列、`false`、`0`) なら中を出さない。

```
■ 連絡
{{or .notes.連絡 "なし"}}
{{- with where .tasks "tags" "ふりかえり"}}

■ ふりかえり
{{- range .}}
- {{.title}}: {{.note}}
{{- end}}
{{- end}}
```

```
■ 連絡
なし

■ ふりかえり
- 週次ふりかえり: 見積りが甘かった
```

ふりかえりのタグが付いた記録がなければ、「■ ふりかえり」の見出しごと出ない。

### 値が空のときの代わりの文字

`or` は、最初の空でない値を返す。

```
{{or .notes.連絡 "なし"}}
```

### プロジェクトのない記録

プロジェクトのない記録は、`code` と `name` が空のまとまりになる。

```
{{- range .projects}}
- {{if .code}}{{.name}}{{else}}その他{{end}}
{{- end}}
```

### 時間不定の記録

プロジェクトの時間に時間不定の記録が混ざっていることを、`has_untimed` で示せる。

```
{{- range .projects}}
- {{.name}}{{if .counted}} ({{.time}}{{if .has_untimed}} +α{{end}}){{end}}
{{- end}}
```

```
- 新機能 (1:30 +α)
- MTG-01 (0:30)
- 
```

タスクごとに出すときは `untimed` を使う。

```
{{range .tasks}}{{.title}}{{if .untimed}} (時間不定){{else}} ({{.time}}){{end}}
{{end}}
```

```
画面の実装 (1:30)
週次ふりかえり (0:30)
調査 (時間不定)
雑談 (0:15)
```

時間未入力の記録 (`time` も `untimed` もない記録) は、`untimed` にならず、時間は `0:00` になる。
時間の入れ忘れなので、コピーや出力の前に警告が出る。

### 真偽値のメモ欄

```
勤務: {{if .notes.在宅}}在宅{{else}}出社{{end}}
```

```
勤務: 在宅
```

### 計上しない記録を分けて出す

前の段落との間に空行を 1 つ入れ、計上しない記録がなければ何も出さない。

```
{{- with where .tasks "exclude" true}}

■ 工数外
{{- range .}}
- {{.title}}
{{- end}}
{{- end}}
```

## 7. CSV の出力 (`*.csv.yaml`)

```yaml
kind: csv
file: "'effort_'yyyyMMdd"
rows: tasks
skip_rows_without_counted: true
columns:
  - header: 日付
    value: '{{date "yyyy/MM/dd"}}'
  - header: コード
    value: '{{.project.code}}'
  - header: タスク
    value: '{{.title}}'
  - header: 時間
    value: '{{duration .minutes "H"}}'
```

```
日付,コード,タスク,時間
2026/03/09,DEV-001,画面の実装,1.5
2026/03/09,MTG-01,週次ふりかえり,0.5
```

| 設定 | 中身 |
| --- | --- |
| `kind` | `csv`。必須 |
| `file`、`encoding` | テキストの出力と同じ。拡張子は `csv` に決まっているので書かない |
| `newline` | `crlf` (省略時) か `lf` |
| `header` | 見出しの行を出すか。省略時 `true` |
| `rows` | 1 行にするもの。`projects` (プロジェクト) か `tasks` (記録)。必須 |
| `skip_rows_without_counted` | `counted` でない行を出さない。省略時 `false` |
| `columns` | 列の並び。1 つ以上。各列は `header` (見出し) と `value` (値のテンプレート。必須) を持つ |

- `value` には、`rows` に合わせて `.projects` か `.tasks` の 1 つの要素が渡る。
  全体の値 (`.date` など) は参照できない。
  日付は `date` 関数で出す。
- 関数はテキストの出力と同じものを使える。
- `,`、`"`、改行を含む値や、空白で始まる値は、アプリが `"` で囲んでエスケープする。

## 8. 出力セット (`*.set.yaml`)

```yaml
kind: set
outputs: [日報テキスト, 工数CSV]
```

- `outputs` は出力の名前の並び。1 つ以上書く。空の名前はエラーになる。
  並びが画面のタブの順になる。
- 同じ出力を 2 回書くとエラーになる。
- ない出力や、誤りがあって使えない出力を指していると、その出力セットを使うときにエラーになる。
- セットの中に、同じファイル名になる出力が 2 つあると、書き出すときにエラーになる。
  大文字と小文字だけが違うファイル名も、同じとみなす (Windows と macOS では同じファイルになるため)。
  プレビューではエラーにしない。

## 9. エラーになるもの

誤りは、空の値として黙って出さずにエラーにする。

- 設定に知らない項目がある、必須の項目がない。
- テンプレートの書き方の誤り (`{{end}}` が足りないなど)。
  テキストの出力では、行番号を、先頭の設定を含めたファイルの行で示す。
- ない値の名前 (`.titel` など) や、その日の記録にも設定にもないメモ欄の名前を参照した。
- `date`、`duration` の書式に誤りがある。
- `where` に、ない項目を指定した。
